# Changelog

Todos los cambios relevantes de este proyecto se documentan en este archivo.

El formato sigue [Keep a Changelog](https://keepachangelog.com/es-ES/1.1.0/) y el proyecto usa [Versionado Semántico](https://semver.org/lang/es/).

## [1.0.0] - 2026-11-26

Versión entregada del portafolio del LRPD.

### Añadido

- Landing del proyecto con gestión según PMBOK 8: EDT, cronograma, costos, riesgos, interesados y calidad (22-nov).
- Demo interactiva del módulo de productos compuestos: ventas de combos, stock, devoluciones, combos por rol, reporte y Kardex (22-nov).
- Rediseño UPSJB: presentación, etapas, planes, Gantt, visor de documentos (22-nov).
- Versión final del LRPD: presupuesto, cronograma V3 con avance, gobernanza, beneficios, valor ganado, cambios y lección aprendida (22-nov).
- Documentos finales y presupuestos por recurso y por entregable (25-nov).

### Cambiado

- Temas visuales sucesivos (Fluent, suavizado) y versión para celular sin desenfoque ni parallax (22-nov).
- Estilo sobrio con secciones numeradas, revisado por el equipo (25-nov).
- README con estructura formal y CHANGELOG (26-nov).
